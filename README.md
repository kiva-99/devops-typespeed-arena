TypeSpeed Arena

DevOps-платформа для тренировки скорости печати с демонстрацией современных практик автоматизации инфраструктуры, CI/CD, мониторинга, логирования и резервного копирования.

============================================================
1. ОПИСАНИЕ ПРОЕКТА
============================================================

TypeSpeed Arena представляет собой веб-приложение для тренировки скорости печати.

Основной целью проекта является демонстрация полного жизненного цикла DevOps-проекта:

- разработка приложения;
- контейнеризация;
- управление инфраструктурой через код;
- автоматизация настройки серверов;
- непрерывная интеграция и доставка;
- мониторинг и логирование;
- резервное копирование и восстановление.

В рамках дипломного проекта основной акцент сделан именно на инфраструктурную составляющую.

============================================================
6. ХРАНЕНИЕ ДАННЫХ
============================================================

PostgreSQL

В базе данных хранятся:

- результаты прохождения тестов;
- статистика пользователей.

Основная таблица:

results

Поля:

id
username
wpm
accuracy
errors
text_id
created_at

------------------------------------------------------------

texts.json

Файл располагается:

app/backend/texts.json

Содержит тексты для тренировки печати.

Backend загружает данный файл при запуске приложения.

Таким образом:

База данных хранит результаты пользователей.

texts.json хранит набор тренировочных текстов.

============================================================
7. CI/CD
============================================================

Реализован автоматический процесс доставки приложения.

Pipeline включает:

1. Сборку Docker image.
2. Публикацию образа в Yandex Container Registry.
3. Подключение к app-node.
4. Обновление контейнеров.
5. Выполнение health-check.
6. Rollback при ошибке.

============================================================
8. МОНИТОРИНГ
============================================================

Prometheus собирает метрики:

- доступность сайта;
- доступность API;
- доступность backend;
- загрузку CPU;
- использование памяти;
- использование диска.

Blackbox Exporter используется для проверки доступности HTTP endpoint.

Grafana используется для визуализации метрик.

============================================================
9. ЛОГИРОВАНИЕ
============================================================

Сбор логов выполняется следующим образом:

Backend
 ->
Promtail
 ->
Loki
 ->
Grafana

Основной лог приложения:

/var/log/typespeed/typespeed-backend.log

Логи доступны для поиска через Grafana.

============================================================
10. АЛЕРТИНГ
============================================================

Используется Alertmanager.

Реализованы уведомления:

- недоступность сайта;
- недоступность health endpoint;
- высокая загрузка памяти;
- высокая загрузка диска.

Уведомления отправляются на электронную почту через Gmail SMTP.

============================================================
11. РЕЗЕРВНОЕ КОПИРОВАНИЕ
============================================================

Резервное копирование PostgreSQL выполняется автоматически.

Схема:

PostgreSQL
 ->
pg_dump
 ->
архивирование
 ->
Object Storage

Проверено восстановление резервной копии в отдельную тестовую базу данных.

============================================================
12. БЕЗОПАСНОСТЬ
============================================================

Реализованы следующие меры:

- SSH доступ только с trusted IP;
- Grafana доступна только с trusted IP;
- Prometheus закрыт от внешнего доступа;
- Alertmanager закрыт от внешнего доступа;
- PostgreSQL доступен только внутри VPC;
- секреты вынесены из репозитория.
